We are actively rebranding and migrating all repositories and asset libraries from `@DaniezOnSFUSD` into **DaniezDev**:

* **New Production Platform:** [daniezdev.github.io/homepage](https://github.io) *(In Active Setup)*

### What We Build

* **Browser Games & Ports:** HTML5, Flash/Ruffle preservation, and Chromebook-optimized web gaming environments.
* **Web Utilities & Experiments:** Custom front-end interfaces, stealth mode tools, and browser-based OS experiments (such as NautilusOS).
