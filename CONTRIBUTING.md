# DaniezDev Contribution Guidelines (Members Only)

**Note:** **DaniezDev** is an invite-only developer organization. **External code contributions and unsolicited Pull Requests from non-members are not accepted** and will be closed automatically.

---

### 1. Organization Member Rules
* **Invite-Only Access:** Only official members of the **DaniezDev** GitHub organization may submit code, bug fixes, or game ports.
* **You Keep Your Code:** Members retain full ownership and credit for any original code or standalone modules they create.
* **Core Code Stays Protected:** All core DaniezDev architectures, UI code, and existing projects remain the exclusive property of Founder **Daniez** (`@DaniezOnSFUSD`).
* **Pull Request Approval Required:** Members cannot push changes directly to protected branches. All edits must be submitted via a **Pull Request (PR)** and explicitly approved by **Daniez** before merging.

---

### 2. Submission Standards for Members
1. **Test on Chromebook Specs:** Ensure all updates run smoothly on ChromeOS without breaking Stealth Mode (`[` / `]`) or existing asset paths.
2. **Credit Third-Party Assets:** Properly attribute any external games, engines, or libraries used.
3. **Protect Core Files:** Do not modify `LICENSE.md`, copyright notices, or SFUSD disclaimers without permission.

---

### Not a Member?
* **Game Requests & Bug Reports:** External visitors can submit game ideas or report broken links through the official request forms at [daniezdev.github.io/homepage](https://github.io).
* **Direct Contact:** Reach out via email at `Daniez1+DaniezDevOrg@proton.me`.
